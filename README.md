# Uncertainty Analysis: MC Dropout, Deep Ensembles and QUAM

This repository contains the analysis code and figures produced during a BSc Practical Work in AI at Johannes Kepler University Linz.

## Scope and provenance

The prediction-generation methods, pretrained model architectures, and core Setting A / Setting B uncertainty functions originate from or were adapted from [ml-jku/quam](https://github.com/ml-jku/quam), associated with *Quantification of Uncertainty with Adversarial Models* (Schweighofer et al., 2023). The student ran the original experimental pipeline to generate prediction files for MNIST, EMNIST and CIFAR-10, then developed/adapted separate scripts for uncertainty visualization and correlation analysis. This repository is **not** a new implementation of the QUAM optimization method.

## Repository overview

- `helper_functions.py` — uncertainty decomposition and plotting/metric utilities; parts adapted from upstream QUAM.
- `make_plots.py` — individual aleatoric-vs-epistemic hexbin figures.
- `correlation_analysis.py` — Pearson/Spearman correlation heatmaps and Setting A/B pairplots.
- `py_combined.py` — four-panel CIFAR-10 comparisons with highlighted extrema.
- `results/` — generated figure outputs; see the Practical Work report for interpretation.
- `data/` — **not committed**; expected locally when running analysis.

## Expected input data

Place the trusted prediction `.pkl` files generated by the upstream pipeline in `data/` with names of the form:

```text
data/
  mcdo_mnist_preds.pkl
  ensembles_mnist_preds.pkl
  quam_mnist_preds.pkl
  mcdo_emnist_preds.pkl
  ensembles_emnist_preds.pkl
  quam_emnist_preds.pkl
  mcdo_cifar10_preds.pkl
  ensembles_cifar10_preds.pkl
  quam_cifar10_preds.pkl
```

Each contains `average_net_pred`, `sample_preds`, and `target`; QUAM may additionally include `train_loss`, `obj_loss`, and other trajectory data. **Do not load `.pkl` files from untrusted sources:** Python pickle deserialization can execute arbitrary code.

## How to regenerate the figures

Install the dependencies in an isolated Python environment, including `torch`, `numpy`, `matplotlib`, `scipy`, `scikit-learn`, `pandas`, and `seaborn`. Adapt the top-of-file dataset and method constants for the figure you want and run, from the repository root:

```bash
python make_plots.py
python correlation_analysis.py
python py_combined.py
```

The scripts currently use constants rather than command-line flags. `correlation_analysis.py` can be replaced by the supplied readable plotting revision; this produces additional PDF versions of the figures.

## Research interpretation and limitations

Settings A and B are two definitions of aleatoric/epistemic uncertainty. Visual correlation does not by itself demonstrate disentanglement or error-detection performance. The current analyses are exploratory: clipping at low values and the choice of QUAM trajectory aggregation affect correlations. Reference the report for precise observations, diagnostic results, and limitations.
